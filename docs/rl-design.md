# 强化学习环境设计

## 1. 任务定义

单个 episode 是机器人从随机起点安全到达一个目标点。应用演示把 4～6 个点到点任务串联为完整巡检路线。

静态地图由 A* 生成全局路径，PPO 只根据局部目标与传感器状态执行动态避障。训练和最终测试使用互不重叠的随机种子。

## 2. 观测空间

目标 Webots 环境使用 79 维 `float32` 向量：

| 内容 | 维度 | 范围 |
|---|---:|---:|
| 36 个 LiDAR 扇区最小距离 | 36 | `[0, 1]` |
| 相邻两帧 LiDAR 距离变化 | 36 | `[-1, 1]` |
| 局部目标距离 | 1 | `[0, 1]` |
| 局部目标方位的 `sin`、`cos` | 2 | `[-1, 1]` |
| 当前线速度、角速度 | 2 | `[-1, 1]` |
| 上一时刻动作 | 2 | `[-1, 1]` |

LiDAR 按扇区取最小值，以保留窄障碍物。距离变化提供简单的接近趋势，但不直接泄露障碍物真实速度。首版不使用相机和 CNN。

## 3. 动作空间

```python
Box(low=-1.0, high=1.0, shape=(2,), dtype=np.float32)
```

- `action[0]` 映射到非负线速度；
- `action[1]` 映射到正负角速度；
- PPO、DWA 和规则法使用相同的速度、加速度和控制频率限制。

原型环境上限为 `0.8 m/s` 与 `1.6 rad/s`，用于快速训练。Webots 环境使用 `0.22 m/s` 与 `1.5 rad/s`，并进一步受 `6.0 rad/s` 轮速、`0.50 m/s²` 线加速度和 `3.0 rad/s²` 角加速度约束。

## 4. 奖励函数

```text
r = 进度奖励
  + 时间惩罚
  + 安全距离惩罚
  + 动作变化惩罚
  + 到达/碰撞终局奖励
```

首版权重：

| 分量 | 定义 |
|---|---|
| 进度 | `3.0 × (上一时刻距离 - 当前距离)` |
| 时间 | 每步 `-0.01` |
| 安全 | 进入安全距离后按接近程度惩罚 |
| 平滑 | 惩罚连续动作差值平方 |
| 到达 | 运动学 `+20`，Webots `+30` |
| 碰撞 | 运动学 `-20`，Webots `-30` |
| 超时 | `-5` |

两个环境均将各奖励分量写入 `info["reward_terms"]`，便于调试和消融。碰撞与到达同一步发生时，以碰撞优先。

## 5. 终止语义

- 安全到达或碰撞：`terminated=True`；
- 达到时间上限或仿真状态不可恢复：`truncated=True`；
- 两者不同时为真。

每步至少记录成功、碰撞、目标距离、最小安全距离、路径长度和步数。

## 6. 场景随机化与课程学习

训练随机化包括起点、目标、障碍数量、障碍速度、运动方向、初始相位和少量 LiDAR 噪声。所有随机结果由 seed 控制并可重放。

已实现的运动学课程：

1. 请求 100k steps：无动态障碍，学习目标跟随；
2. 请求 150k steps：2 个低速动态障碍；
3. 请求 300k steps：5 个标准动态障碍；
4. 请求 250k steps：7 个高密度、高速动态障碍。

运动学 PPO 使用 `MlpPolicy`、两层 128 单元网络、学习率 `3e-4`、`gamma=0.99`、`gae_lambda=0.95`、CPU。Webots 微调使用新的优化器和 `1e-4` 学习率。课程、恢复和模型选择流程见[训练复现协议](training-protocol.md)。

## 7. 基线

- 规则避障：前方过近则减速并朝空旷侧转向；
- DWA：在相同速度约束内采样局部轨迹并评分；
- 本项目方法：A* + PPO。

三者共享地图、全局路径、控制频率、传感器范围、速度上限和测试种子。
