# 微信小程序账号资料草案

## 头像

![室内智能巡检小程序头像](assets/wechat-miniprogram-avatar-v1.png)

头像采用“轮式巡检机器人、LiDAR 扫描、动态避障与导航路径”的组合图形，主体位于中央安全区域，适合微信方形展示与圆形裁切。

## 小程序介绍

面向室内智能巡检场景，实时展示机器人位置、巡检路线、任务进度及温度、烟雾、一氧化碳等环境数据，发现异常自动告警，让用户随时掌握巡检状态与历史记录。

## 当前边界

本资料用于小程序账号和后续客户端设计。当前已实现的是 Mac mini 本机运行的只读网页看板；微信小程序客户端、远程数据服务和真机访问尚未实现，不能在账号介绍中声称已经上线。
